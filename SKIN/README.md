# POP PUNK GUITAR ULTIMATE — SKIN packs

10 separate theme packs. Each contains `theme.json` (palette and UI tokens) and `preview.svg` (scalable visual concept preview).

- `Skin_01_Obsidian_Black/` — Obsidian Black
- `Skin_02_Sunburst_Deluxe/` — Sunburst Deluxe
- `Skin_03_Neon_Cyber/` — Neon Cyber
- `Skin_04_Carbon_Pro/` — Carbon Pro
- `Skin_05_Platinum/` — Platinum
- `Skin_06_Vintage_Studio/` — Vintage Studio
- `Skin_07_Electric_Blue/` — Electric Blue
- `Skin_08_Royal_Purple/` — Royal Purple
- `Skin_09_Blood_Red/` — Blood Red
- `Skin_10_Arctic_White/` — Arctic White

All themes share the same layout and cover MELODY, PATTERN, AMP & TONE, Reverb, Flanger, Chorus, Delay, Distortion, Playback and voice/performance panels. Theme data is presentation-only and must not alter audio, MIDI, presets or transport.

**Integration status:** these are separate theme palette packs and SVG previews. They are not yet connected to the JUCE editor/runtime. Runtime work still required: one SKIN picker, loading tokens, applying them to real controls, and persisting the selected ID. The `assets` map is intentionally empty; no missing artwork paths are advertised. `RESOURCE` remains separate for shared UI assets.

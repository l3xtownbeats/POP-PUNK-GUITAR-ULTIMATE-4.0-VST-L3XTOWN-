# Bundled font fallback — NEON STAGE

Inter variable font is included as a license-clean optional fallback.

- File: `Inter[opsz,wght].ttf`
- Source: `google/fonts/ofl/inter`
- License: SIL Open Font License 1.1, copied in `OFL.txt`
- Integrity: see `font_manifest.json` (Git blob SHA-1, byte count and CRC32).

The existing NEON STAGE typography remains Segoe UI / Consolas. This file is
not automatically activated by the UI; ThemeManager font loading must be
implemented and tested separately before changing the active typography.

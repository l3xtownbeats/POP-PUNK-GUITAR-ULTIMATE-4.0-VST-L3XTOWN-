PPGU VISUAL CORE — COMPACT (REV 18)
Сжатая выжимка: только визуальный слой — тема, окна, кнопки, браузеры, вкладки.
Источник истины: PPGU MASTER PROMPT REV 18 v6.2 (полная версия — арбитр при конфликтах).

1. ТЕМА
- NEON STAGE DEFAULT SKIN-1 = skin-053: дефолтная визуальная тема интерфейса
  плагина на МИНИМАЛЬНЫХ ресурсах CPU/RAM. Всегда первая, default, fallback, reset.
- SOUND FORGE = NEON STAGE (отдельной темы нет). SIGNAL FORGE — только стандарт.
- Остальные темы: строго SKIN-2, SKIN-3, SKIN-4… без пропусков и перенумерации.
- Релизная галерея: ровно 16 тем (SKIN-1…SKIN-16); legacy-имена (Neon Riot,
  Dark Metal, Modern Studio, Carbon Relay, Blackout Voltage) — история, не активные.
- Конфликт реестра (skin-052 default) — только no-loss migration audit.

2. ПАЛИТРА И ДИЗАЙН-СИСТЕМА
- 21 HEX token, primary ≥ 7:1 к окну. ZERO hardcoded HEX в PluginEditor.cpp
  и Source/UI/* — только canonical tokens через ThemeManager::applyPalette.
- Layout STUDIO_CONSOLE, сетка 12×16, 27 control-ID parity.
- Единый дизайн-стандарт: все окна/панели/меню наследуют NEON STAGE.

3. ГЛАВНОЕ ОКНО — ЗОНЫ A–H
- A TOP BAR: SKINS | Import Guitar | Auto Discover | Curator | Settings | About.
  Нереализованное = disabled, честно.
- B BROWSER: пресеты, категории, поиск, статус-строка.
- C PLAYING CORE: MELODY/PATTERN, hero artwork, 9 rotary.
- D FX CHAIN: 7 эффектов; on/off = реальный DSP routing.
- E AUTOCHORDS: setup-only; чипы (OPEN CHORDS…OCTAVE HOOK); selection независим;
  display НИКОГДА не перекрывает MIDI-клавиатуру.
- F FX EDIT: 1 окно, 8 страниц, 7 bypass.
- G AMP & TONE: amp model, Gain/Bass/Treble.
- H PERFORMANCE: read-only MIDI monitor. НЕТ BPM/баров/CPU/RAM/wheels.
- НЕ изображать: PREV/NEXT/FAVORITE/SAVE пресетов, PUNK GROUP, LED, wheels,
  CPU/RAM meters.

4. ОКНА И ВКЛАДКИ
- 5 auxiliary-окон (DocumentWindow, нативный title bar off, JUCE bar = X +
  квадрат maximize/restore): FX EDIT | AUTOCHORDS (disabled) | IMPORT GUITAR
  (async SFZ, drop-zone+Browse, LOADING/SUCCESS/FAILURE) | SETTINGS (6 controls)
  | PERFORMANCE (read-only).
- Геометрия tiled: 1=single, 2=2x1, 3–4=2x2, 5–6=2x3; нехватка места → focus
  paging, не overlap; maximize через правый dock.
- Persistence в PropertiesFile с clamp к work area; X не убивает состояние;
  hot-swap visual-only (150 мс); аудиопатч не зависит от UI.

5. КНОПКИ И КОНТРОЛЫ
- 9 rotary с точными APVTS ID и диапазонами; 7 FX bypass (bool); SKIN button
  (Ctrl+K); MIDI keyboard 36–84 (подсветка = реальный MIDI state: hover=warning,
  active=ledOn, focus=highlight, FX success=success).
- Состояния всех контролов: hover/pressed/focus/disabled — из палитры токенов.
- FLANGER: страница есть, enable-переключателя НЕТ — восьмой switch не создавать.

6. РЕСАЙЗ ОКНА (A5-R)
- Правый край → ширина; нижний край → высота; правый нижний угол → обе оси
  (живой resize, без лагов).
- Содержимое плавно увеличивается/уменьшается вместе с окном: без обрезаний,
  наложений зон, перекрытия клавиатуры и мыльных апскейлов (масштаб из мастеров).
- При drag-resize — перерисовка только изменённых областей.

7. АССЕТЫ (A6-D)
- Коммерческое качество, максимум разрешения: контролы/спрайты ≥512×512,
  hero ≥1600×900 (runtime 800×450), preview ≥720×480 (runtime 360×240),
  texture ≥1024×1024 бесшовная, фон ≥2560×1440. Мастера хранятся отдельно.
- Контроль: резкость 100%, чистые края, палитра только из токенов, PNG CRC.
- Placeholder — только с явной пометкой, никогда за готовый ассет.
- Автогенерация разрешена и обязательна при необходимости: по журналу/макетам
  или с нуля ([DECISION]).

8. ЭФФЕКТЫ И АНИМАЦИИ (A6-E)
- Блики, отражения, свечения, тени, градиенты, неоновые обводки, specular;
  единый источник света; цвета эффектов = производные токенов.
- Живые анимации: hot-swap 150 мс, ручки/слайдеры с бликом и дугой значения,
  hover/pressed/focus с easing, key-reactive подсветка клавиатуры.
- Запрещено анимировать CPU/RAM/LED/транспорт. Тяжёлое — в baked-слои (PNG),
  не в кадре. Цель 60 FPS.

9. РЕСУРСЫ И РЕЖИМЫ (A6-F/G/H)
- По умолчанию МИНИМАЛЬНОЕ потребление RAM/CPU/GPU/видеоядра; максимум
  ресурсов НЕ используется без явной необходимости.
- GPU/HiDPI 100–400%/4K–8K/мультимонитор/антиалиасинг/atlas — только по
  необходимости и с минимальными затратами; HiDPI рендер строго по реальному
  масштабу экрана.
- Режимы отображения: «ЭФФЕКТЫ» (полный премиум) и «МИНИМАЛИЗМ» (чистый
  стандарт). ДЕФОЛТ = МИНИМАЛИЗМ. Переключатель в SETTINGS + SKIN-меню,
  сохраняется между сессиями, самовольно ничего не переключается.
- Минимализм — режим той же темы, не другая тема: палитра/layout идентичны.
- Простой/свёрнутый редактор: анимации и repaint приостанавливаются; busy-wait
  запрещён; эффективность подтверждается замерами, не декларациями.

- Не менять аудио-код/APVTS ID/MIDI/пресеты в skin/UI этапах.
- Лицензионно-чистая графика только; всё проходит G1–G4 + PNG CRC.

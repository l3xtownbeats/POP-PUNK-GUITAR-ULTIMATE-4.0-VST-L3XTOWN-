## 0. РОЛЬ
Ты — арт-директор и технический художник премиального аудиософта
(Serum/Pro-Q/Omnisphere-уровень полировки), плюс инженер ассет-пайплайна.
Ты работаешь над темой VST3-плагина в стиле «неоновая студийная сцена»:
тёмный металл, подсвеченное стекло, честная физика света, точная типографика.
Ты НЕ делаешь «дешёвую поделку»: ни плоских серых прямоугольников вместо
контролов, ни эмодзи вместо иконок, ни случайных градиентов.

## 2. ПОЛНЫЙ СОСТАВ ТЕМЫ — ЧТО ИМЕННО СДАТЬ
Runtime-папка: `Skins/` рядом с установленным .vst3 (НЕ AppData).
Структура темы (для главной: `Skins/skin-053/`):

   Skins/skin-053/
     theme.json                 — палитра, layout, маппинг, флаги
     assets/controls/*.png      — спрайты контролов по кадрам состояний
     assets/hero/*.png          — hero artwork (мастер + runtime)
     assets/preview/*.png       — превью галереи (мастер + runtime)
     assets/textures/*.png      — бесшовные текстуры ≥1024×1024
     assets/background/*.png    — фон главного окна ≥2560×1440
     assets/fx_layers/*.png     — baked-слои эффектов с альфой
     assets/icons/*.svg|png     — иконки TOP BAR и служебные
     fonts/                     — лицензионно-чистый шрифт
     atlas/                     — texture atlas + описание кадров
   Плюс: Skins/theme_manifest.json (живой реестр всех тем) и
   Skins/control_schema.json (27 control-ID, 21 токен, inventory).

Минимальные размеры мастеров (мастера хранить отдельно, runtime-экспорт
их НЕ перезаписывает):
   - контролы/спрайты: ≥512×512 НА КАЖДЫЙ кадр состояния;
   - hero artwork: мастер ≥1600×900, runtime 800×450;
   - preview галереи: мастер ≥720×480, runtime 360×240;
   - текстуры: ≥1024×1024, бесшовные (tileable);
   - фон: ≥2560×1440;
   - иконки: SVG-исходник + PNG-экспорт нужных плотностей.

## 3. ГРАФИЧЕСКИЙ СТАНДАРТ КАЧЕСТВА («НЕ ПОДЕЛКА»)
3.1. Материалы: тёмный шлифованный металл, матовый пластик, подсвеченное
   стекло, неоновые кромки. Глубина достигается BAKED-СЛОЯМИ (PNG с альфой:
   блики, свечения, отражения, тени, градиенты, неоновые обводки, specular),
   НЕ пересчитываемыми шейдерами в кадре.
3.2. Единый источник света на всю тему. Тени и блики согласованы во всех
   элементах. Никаких «свет сверху» у одних элементов и «свет снизу» у других.
3.3. Палитра: РОВНО 21 HEX-токен — единственный источник цветов.
   ZERO hardcoded HEX. Контраст primary ≥ 7:1 к окну (референс Skin_052:
   primary 17.81, secondary 10.79, disabled 5.23, LCD 17.17, accent 15.09).
   Цвета состояний — семантические токены: hover/active/disabled/success/
   warning/error; произвольные цвета запрещены.
3.4. Сетка 12×16 (layout STUDIO_CONSOLE): все размеры элементов кратны сетке.
   Плотные интервалы, выровненные оптические оси, единая типографическая
   система (лицензионно-чистый шрифт, без произвольных размеров).
3.5. Качество рендера: резкость 100%, чистые края без ореолов, без артефактов
   сжатия, без мыльных апскейлов, без водяных знаков, без чужих логотипов.
   Спрайты состояний одного элемента — идеальная геометрическая соосность
   (ручка не «прыгает» между кадрами).
3.6. Язык иконок единый: линейные/монохромные с одной неоновой акцентной
   кромкой, одинаковая толщина линий, единый оптический размер.

## 4. ГЛАВНОЕ ОКНО — ЗОНЫ A–H (все изобразить графически)
A TOP BAR: SKINS | Import Guitar | Auto Discover | Curator | Settings | About —
   шесть точек входа обязательны; нереализованное = disabled, честно.
B BROWSER: список пресетов, категории, поиск, статус.
C PLAYING CORE: переключатель MELODY/PATTERN, hero artwork, 9 rotary.
D FX CHAIN: 7 эффектов; on/off = реальный DSP routing, не декорация.
E AUTOCHORDS (setup-only до backend): HARMONY PRESETS, PLAYING STYLE/
   ARTICULATION, PLAYBACK MODE, RHYTHM MODE, Pattern Browser + РОВНО 16 чипов:
   OPEN CHORDS, PALM MUTE, POWER CHORDS, DOWNSTROKE, ALTERNATE, CHUGS, SKANK,
   ARPEGGIO, STRAIGHT 8THS, FAST SKATE-PUNK, GALLOP, HALF-TIME, STOP-START,
   VERSE→CHORUS, OFFBEAT, OCTAVE HOOK. Выбранный чип визуально выделен
   (active-токен); selection независим для гармонии и ритма; Display НИКОГДА
   не перекрывает MIDI-клавиатуру.
F FX EDIT: одно окно, 8 страниц, 7 bypass.
G AMP & TONE: amp model, Gain/Bass/Treble — реальный тракт.
H PERFORMANCE: read-only MIDI monitor. БЕЗ BPM/баров/CPU/RAM/wheels.

## 5. ЭЛЕМЕНТЫ УПРАВЛЕНИЯ — РИСУЙ КАЖДЫЙ, ПО КАЖДОМУ ВСЕ КАДРЫ СОСТОЯНИЙ
5.1. 9 ручек (круглая ручка с дугой значения и бликом в режиме ЭФФЕКТЫ;
   статичный честный указатель в МИНИМАЛИЗМЕ; подпись PID у основания;
   drag по вертикали/дуге; двойной клик = сброс; значение при drag):
   ampGain 0..10 def 5 (гейн усилителя, зона C)

   velocity 0..2 def 1 | dynamics 0..1 def 0.5 | swing 0..1 def 0 |
   humanize 0..1 def 0 | accent 0..1 def 0.75 (зона C)
5.2. 7 FX-тумблеров (индикатор on/off: on = активная палитра, off =
   приглушённый + disabled-контраст; cabinetOn честно disabled без IR):
   compressorOn, eqOn, distortionOn, chorusOn, delayOn, reverbOn, cabinetOn.
   ВОСЬМУЮ КНОПКУ (flanger) НЕ СОЗДАВАТЬ.
5.3. Селекторы: preset selector (строка выбора с активной подсветкой),

   LOAD SFZ (= Import Guitar), patternSlot 0..7 (8 ритм-масок, ≠ секции),
   SKIN button (Ctrl+K, открывает галерею).
5.4. MIDI-клавиатура 36–84: клик = реальные ноты; подсветка ТОЛЬКО по
   реальному MIDI-стейту: hover=warning, active=ledOn, search focus=highlight,
   FX success=success; плавное затухание.
5.5. Чипы AUTOCHORDS — все 16 как кликабельные плитки с состоянием active.
5.6. ЗАПРЕЩЕНО ИЗОБРАЖАТЬ: PREV/NEXT/FAVORITE/SAVE пресетов, PUNK GROUP,

## 7. RESIZE
Правый край → ширина; нижний край → высота; правый нижний угол → обе оси.
Содержимое плавно масштабируется вверх и вниз без обрезаний, наложений зон
и мыльных апскейлов (из мастеров). Минимальные границы = читаемость всех зон.

## 8. РЕЖИМЫ И РЕСУРСЫ
Дефолт МИНИМАЛИЗМ (минимальное CPU/RAM/GPU; статичные честные контролы);
ЭФФЕКТЫ — только по явному выбору (дуги, блики, easing). Максимум качества
на единицу ресурсов: baked-слои, texture atlas вместо дубликатов, repaint
по областям. ECO упрощает анимации. Анимация отражает ТОЛЬКО реальное
состояние плагина.

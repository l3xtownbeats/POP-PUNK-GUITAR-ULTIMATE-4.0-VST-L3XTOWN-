# PPGU UI THEME SPEC — REV 18 (v1.3 — FULL CONTROL REFERENCE EDITION)
# Полная спецификация визуального слоя и интерфейса для создания темы.
# Только визуал и управление: без аудио-движка, сэмплов, Sound Hunter и CI.
# Источник фактов: SKIN/control_schema.json (27 control-ID, 21 token) + master prompt v6.2.

## 1. ТЕМА-СТАНДАРТ
- NEON STAGE DEFAULT SKIN-1 (= skin-053/Skin_053) — дефолтная визуальная тема
  интерфейса плагина с использованием минимальных ресурсов CPU RAM.
- Максимальные ресурсы НЕ используются без явной необходимости; качество
  достигается инженерией (baked-слои, texture atlas, кэширование, repaint
  по областям), а не расходом ресурсов.
- SOUND FORGE = SIGNAL FORGE (имя темы) = NEON STAGE; отдельных тем с этими
  именами не создавать нигде: ни в реестре, ни в галерее, ни в UI.
- Нумерация остальных тем строго по порядку: SKIN-2, SKIN-3, SKIN-4… без
  пропусков и перенумерации. NEON STAGE всегда первая и по умолчанию.
- Все окна, панели, меню наследуют палитру/типографику/компоненты через
  ThemeManager::applyPalette — единая дизайн-система на всё приложение.
- Legacy-имена (Neon Riot, Dark Metal, Modern Studio, Carbon Relay,
  Blackout Voltage) — исторические записи реестра, НЕ активные темы.
- Релизная галерея: ровно 16 тем. NEON STAGE DEFAULT без редизайна.
- Runtime: скины лежат ровно в `Skins/` рядом с установленным .vst3 (не AppData).
- Схемы НЕ взаимозаменяемы: legacy theme.schema.json = Skin_01..51;
  control_schema.json = Skin Studio 52+.
- Валидация G1–G4: tools/validate_skin_pack.py; merge: tools/merge_skin_pack.py.

## 2. ПАЛИТРА И СЕТКА
- 21 HEX token — единственный источник цветов. Хардкодить HEX в UI запрещено.
- Контраст primary ≥ 7:1 к окну (референс Skin_052 Carbon Relay: primary 17.81,
  secondary 10.79, disabled 5.23, LCD 17.17, accent 15.09).
- Layout STUDIO_CONSOLE, сетка 12×16, 27 control-ID parity.
- Flags APVTS/layout/audio = false: тема не меняет параметры, позиции
  контролов и аудиотракт.
- Единый источник света на всю тему; цвета состояний: warning, ledOn,
  highlight, success, disabled — семантические токены, не произвольные.

## 3. ГЛАВНОЕ ОКНО — ЗОНЫ A–H
A TOP BAR: SKINS | Import Guitar | Auto Discover | Curator | Settings | About.
  Точки входа обязательны; нереализованное = disabled, честно.
B BROWSER: пресеты, категории, поиск, статус.
C PLAYING CORE: MELODY/PATTERN/(PUNK GROUP slot), hero artwork, 9 rotary.
D FX CHAIN: 7 эффектов; on/off = реальный DSP routing, не декорация.
E AUTOCHORDS: setup-only до backend. HARMONY PRESETS, PLAYING STYLE/
  ARTICULATION, PLAYBACK MODE, RHYTHM MODE, Pattern Browser, 16 чипов:
  OPEN CHORDS, PALM MUTE, POWER CHORDS, DOWNSTROKE, ALTERNATE, CHUGS, SKANK,
  ARPEGGIO, STRAIGHT 8THS, FAST SKATE-PUNK, GALLOP, HALF-TIME, STOP-START,
  VERSE→CHORUS, OFFBEAT, OCTAVE HOOK. Selection независим для гармонии и
  ритма, визуально выделен. Display НИКОГДА не перекрывает MIDI-клавиатуру.
F FX EDIT: одно окно, 8 страниц, 7 bypass. Цель REV.18: 10–15 реальных
  DSP-эффектов (сейчас 7 слотов — gap).
G AMP & TONE: amp model, Gain/Bass/Treble — реальный тракт.
H PERFORMANCE: read-only MIDI monitor. НЕТ BPM/баров/CPU/RAM/wheels.

## 4. СПРАВОЧНИК ЭЛЕМЕНТОВ УПРАВЛЕНИЯ (PID = единственно допустимый APVTS ID)

### 4.1 Ручки (9 rotary) — зона C / G
| PID         | Диапазон   | Дефолт | Функция                         | Зона |
|-------------|-----------|--------|---------------------------------|------|
| ampGain     | 0..10     | 5      | Гейн усилителя (громкость тона)  | C    |
| eqHigh      | −12..12   | 0      | ВЧ-эквалайзер                    | G    |
| eqMid       | −12..12   | 0      | СЧ-эквалайзер                    | G    |
| eqLow       | −12..12   | 0      | НЧ-эквалайзер                    | G    |
| velocity    | 0..2      | 1      | Чувствительность к velocity      | C    |
| dynamics    | 0..1      | 0.5    | Динамическая выразительность     | C    |
| swing       | 0..1      | 0      | Свинг-смещение ритма             | C    |
| humanize    | 0..1      | 0      | Микро-вариативность игры         | C    |
| accent      | 0..1      | 0.75   | Сила акцента                     | C    |
ВИД: круглая ручка с дугой значения и бликом (режим ЭФФЕКТЫ) либо статичный
честный указатель (МИНИМАЛИЗМ). Подпись PID у основания.
ПОВЕДЕНИЕ: drag по вертикали/дуге; двойной клик = сброс к дефолту;
изменение двигает реальный параметр APVTS; easing-анимация движения в
ЭФФЕКТЫ. Значение отображается по требованию/при drag.

### 4.2 FX bypass (ровно 7, bool) — зона D
compressorOn, eqOn, distortionOn, chorusOn, delayOn, reverbOn, cabinetOn.
ВИД: тумблер-кнопка с индикатором on/off; on = активная палитра,
off = приглушённый цвет + disabled-контраст.
ПОВЕДЕНИЕ: клик = реальный DSP-routing (вкл/выкл эффекта), не декорация.
cabinetOn честно disabled без IR-ассетов. Восьмую кнопку (flanger) НЕ
создавать: flangerOn есть в процессоре, но НЕ в inventory — страница есть,
enable-переключателя нет.

### 4.3 Селекторы и служебные элементы
- preset selector (зона B): выбор пресета из браузера; вид = строка выбора
  с активной подсветкой; клик = загрузка пресета.
- category filter (B): фильтр категорий пресетов; вид = выпадающий список.
- preset search (B): текстовый поиск; focus = подсветка highlight.
- status label / LCD_display (глобально): ЕДИНСТВЕННЫЙ источник сообщений
  (статусы, ошибки, результаты); вид = LCD-панель, контраст LCD-токена.
- MELODY/PATTERN (C): переключатель режима пресетов; PUNK GROUP в playMode
  отсутствует — не изображать третьим пунктом.
- sync selector (C): синхронизация темпа/грува; вид = селектор.
- LOAD SFZ = Import_Guitar (top bar Import Guitar): открытие SFZ-импорта.
- SKIN button (top bar SKINS): открытие галереи тем; хоткей Ctrl+K.
- patternSlot 0..7 (E): 8 ритм-масок (≠ секции; section-first UX — gap).
- MIDI keyboard 36–84 (нижняя зона): экранные клавиши; клик = реальные
  ноты; подсветка ТОЛЬКО по реальному MIDI-стейту: hover=warning,
  active=ledOn, search focus=highlight, FX success=success.

### 4.4 TOP BAR (зона A) — функции точек входа
SKINS — галерея тем (Ctrl+K). Import Guitar — импорт SFZ (async).
Auto Discover / Curator / Settings / About — точки входа в свои окна;
нереализованное = disabled, честно помечено.

### 4.5 Чипы AUTOCHORDS (зона E) — 16 штук
Каждый чип = кликабельная кнопка-плитка выбора ритма/артикуляции; выбранный
чип визуально выделен (active-токен); selection независим для гармонии и
ритма. Список — в разделе 3, зона E. До backend — setup-only.

### 4.6 Отсутствуют и НЕ изображать готовыми
PREV/NEXT/FAVORITE/SAVE пресетов, BPM, транспорт, метры уровня, wheels,
«декоративно крутящиеся» элементы, CPU/RAM-метры.

## 5. ОКНА И ПАНЕЛИ
Главное окно = зоны A–H (раздел 3). Пять auxiliary-окон: top-level
DocumentWindow, native title bar off, JUCE bar = X + квадрат
maximize/restore. Все наследуют тему NEON STAGE.
- FX EDIT: параметры выбранного эффекта; 8 страниц, 7 bypass; открытие
  показывает страницу активного эффекта из FX CHAIN.
- AUTOCHORDS: disabled до backend — окно открывается честно неактивным.
- IMPORT GUITAR: drop-zone + Browse; async SFZ-загрузка со статусом
  LOADING → SUCCESS/FAILURE через LCD/setStatus; план: preview, отмена,
  toggle WAV-конвертации без перезаписи, root key, velocity layers, RR,
  articulations, gain/tune/pan, group/off_by.
- SETTINGS: ровно 6 существующих APVTS controls; допустимы к утверждению:
  profiles GOOD/NORMAL/NIGHT/ECO, quality 2x/4x/8x/16x, Voices в пределах
  capacity; здесь же переключатель режимов ЭФФЕКТЫ/МИНИМАЛИЗМ.
- PERFORMANCE: read-only MIDI monitor; BPM/бары/CPU/RAM/wheels отсутствуют.
- ABOUT (точка входа TOP BAR): L3XTOWN | POP PUNK GUITAR ULTIMATE VST3 |
  REV.18 | 2026 | фактическая engine/build version; RU/EN мануалы.
ПОВЕДЕНИЕ ОКОН: X закрывает окно БЕЗ потери состояния; maximize/restore —
квадрат в JUCE-баре; tiled-геометрия, focus paging при нехватке места;
hot-swap темы = 150 мс плавно; состояние окон persist в PropertiesFile.

## 6. BROWSER И SKIN-ГАЛЕРЕЯ
Gallery: есть cards/search/family/count/active marker; клик немедленно
грузит тему. НЕТ: Preview/Apply/Back/cancel, enlarged preview, Favorites,
keyboard nav, persistence-тесты. Порядок доработки: selection state →
Preview/Apply/Back → остальное.

## 7. RESIZE ОКНА И МАСШТАБИРОВАНИЕ ЭКРАНА
- Правый край → ширина; нижний край → высота; правый нижний угол → обе
  оси сразу. Живой resize в реальном времени, без лагов.
- Экран (содержимое) УВЕЛИЧИВАЕТСЯ и УМЕНЬШАЕТСЯ вместе с окном: плавное
  пропорциональное масштабирование — без обрезания, наложений зон A–H,
  перекрытия MIDI-клавиатуры и мыльных апскейлов (мастер-ассеты по разд. 9).
- Layout по сетке 12×16 и правилам tiled/focus paging; при нехватке места —
  focus paging, не overlap.
- Минимальные границы окна = читаемость всех зон; размер/позиция сохраняются
  в PropertiesFile с clamp к рабочей области.
- При drag-resize — экономная перерисовка изменённых областей, не полный
  repaint каждый кадр.

## 8. СОСТОЯНИЯ И АНИМАЦИИ
- hover / pressed / focus / dragged — у всех интерактивных элементов, с
  easing; smooth hot-swap 150 мс; мягкие переходы состояний FX и панелей;
  честная индикация загрузки.
- Key-reactive подсветка клавиатуры с плавным затуханием по реальному
  MIDI-стейту.
- Анимация отражает ТОЛЬКО реальное состояние. Запрещено анимировать
  CPU/RAM-метры, LED, транспорт (A7). Тяжёлый блюр/шейдеры не пересчитываются
  в кадре — baked-слои (PNG с альфой) или кэш. ECO упрощает анимации.

## 9. АССЕТЫ
- Всё — PNG, SVG, спрайты, текстуры, hero, preview, фон, иконки — максимум
  разрешения и коммерческое качество: без артефактов сжатия, размытия,
  мыльных апскейлов, водяных знаков, чужих логотипов.
- Минимумы мастеров: контролы/спрайты ≥512×512/кадр; hero ≥1600×900
  (runtime 800×450); preview ≥720×480 (runtime 360×240); текстура ≥1024×1024
  бесшовная; фон ≥2560×1440. Мастера отдельно, runtime-экспорт не
  перезаписывает.
- Контроль: резкость на 100%, чистые края, палитра только из canonical
  tokens, PNG CRC проходит G3. Placeholder — только с явной пометкой.

## 10. РЕЖИМЫ И РЕСУРСЫ
- Режимы отображения: «ЭФФЕКТЫ» (полный премиум: блики, отражения, свечения,
  живые анимации) и «МИНИМАЛИЗМ» (чистый стандартный вид без доп. эффектов).
- ДЕФОЛТ = МИНИМАЛИЗМ: первый запуск, сброс и fallback — минимализм с
  минимальным потреблением CPU, RAM, графической памяти и видеоядра.
- Переключатель: SETTINGS + быстрый доступ из SKIN-меню; сохраняется между
  сессиями; ничего не переключается самовольно.
- Минимализм — НЕ другая тема, а режим ОДНОЙ темы NEON STAGE DEFAULT SKIN-1:
  палитра, layout и состав контролов идентичны, различаются только слои
  эффектов/анимаций.
- Базовая линия: минимальное потребление в любых состояниях, включая простой
  и свёрнутый редактор. CPU: без busy-wait, анимации 30–60 Гц по
  необходимости, приостановка при неактивности, repaint по областям.
  GPU: рендеринг только при изменениях, статичные слои кэшируются.
- Возможности (GPU-ускорение, HiDPI 100–400%, 4K/8K, мультимонитор,
  антиалиасинг, texture atlas, 60 FPS) — доступны, включаются только при
  реальной необходимости и с минимальными затратами. Правило: максимум
  качества на единицу ресурсов, минимум абсолютного потребления.

## 11. ЗАПРЕЩЕНО ИЗОБРАЖАТЬ КАК РЕАЛИЗОВАННОЕ
Пресет-кнопки PREV/NEXT/FAVORITE/SAVE; BPM; транспорт; метры уровня; wheels;

фиктивная активность в панелях; performance-данные до realtime-safe
transport snapshot.

# PPGU — ЕДИНЫЙ АРХИВ ЖУРНАЛОВ И СПЕЦИФИКАЦИЙ

Каноническое расположение журналов проекта: docs/PPGU_JOURNAL/.

## Состав архива
- INFO.md — решения, требования, статусы, проверки и контрольные точки (копия прежнего Info.txt).
- CODE.md — карта исходников и история изменений кода, путей, символов, commit SHA и тестовых свидетельств (копия прежнего CODE.txt).
- PPGU_GUITAR_SOUND_LIBRARY_MASTER_PLAN_RU.md — план библиотеки и строгий размер 25–30 GB.
- PPGU_MASTER_PROMPT_RU.md — мастер-инструкции.
- PPGU_MAJOR_USER_REQUIREMENTS_AMENDMENT_2026-11-14_RU.md — утверждённые поправки.
- PPGU_AUDIO_ENGINE_PRODUCT_FAMILY_RU.md — карта аудио-движка.
- MASTER_PRODUCT_SPEC_4_0_RU.md — мастер-спецификация.
- PRESET_BANK_4_0_READINESS_RU.md — журнал готовности банка пресетов.
- SAMPLE_LIBRARY_SOURCING_AND_LICENSE_POLICY.md — политика источников и лицензий.
- PPGU_CANONICAL_PUNK_GROUP_PRESET_SOUND_MAP_RU.md — каноническая карта групп/звука/пресетов.

## Обязательные правила ведения
1. Все дальнейшие журнальные записи и спецификации вести в этой папке; новые параллельные журналы вне неё не создавать.
2. INFO.md и CODE.md — разные, синхронные журналы. Обновлять оба в рамках одной рабочей операции, указывать общий commit SHA, затронутые пути/символы, причину, тестовые команды и реальные результаты; затем повторно считывать и проверять оба.
3. Полный исходный код хранить в соответствующих .cpp/.h. В журналы записывать только карту, описание изменений и доказательства — не копировать исходники целиком.
4. APPROVED, DOCUMENTED, VERIFIED, IMPLEMENTED, TESTED, SIZE-VERIFIED и COMPLETE не взаимозаменяемы. Незапущенные тесты отмечать NOT RUN.
5. По точному запросу пользователя ALL подготовить и прикрепить скачиваемый ZIP, содержащий все файлы этой папки с актуального main. Архив формировать заново при каждом таком запросе, чтобы он отражал актуальные записи.
6. Старые корневые Info.txt/CODE.txt и исходные документы пока оставлены как исторические исходники копирования. Их удаление/перемещение не выполнено: до этого требуется полный аудит всех ссылок, CI/workflows, скриптов и потребителей, чтобы не потерять историю и не сломать сборку.

## Размер factory Guitar Sound Library
Строго 25–30 GB фактических аудио-активов. См. PPGU_GUITAR_SOUND_LIBRARY_MASTER_PLAN_RU.md. Это требование APPROVED/DOCUMENTED, но пока не SIZE-VERIFIED.

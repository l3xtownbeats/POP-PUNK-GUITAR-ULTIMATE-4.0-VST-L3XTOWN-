# PPGU — КАНОНИЧЕСКИЙ ЖУРНАЛ И ДОКУМЕНТАЦИЯ

## Единственный рабочий журнал (все темы, кроме кода)
- **PPGU_JOURNAL.md** — единый append-only журнал проекта: решения, требования, статусы, архитектура, звук, библиотеки, лицензии, пресеты, UI/UX, задачи, ошибки, исправления, проверки, сборки, релизы и все прочие не-кодовые события.

## Единственный отдельный журнал кода
- **CODE.md** — история изменений исходного кода: commit SHA, файлы/символы, причина, тестовые команды и реальные результаты. Исходники остаются в .cpp/.h и других production-файлах.

## Правила ведения
1. Все новые не-кодовые журнальные записи добавлять только в `PPGU_JOURNAL.md` сразу по ходу выполненной работы.
2. Все изменения production source отражать в `CODE.md`; соответствующий общий статус/результат — в `PPGU_JOURNAL.md`.
3. Не создавать новые активные журналы, включая отдельные журналы пресетов, библиотек, UI, тестов или релизов. Их записи относятся в единый журнал.
4. Спецификации и планы могут оставаться отдельными справочными документами, но не являются журналами и не должны дублировать текущую хронологию.
5. Старые `INFO.md`, `Info.txt` и `PRESET_BANK_4_0_READINESS_RU.md` сохранены как архивные указатели/исторические копии; актуальные записи ведутся только в `PPGU_JOURNAL.md`.
6. При запросе пользователя `ALL` сформировать свежий ZIP архива документации, включая единый журнал, CODE и все актуальные спецификации.

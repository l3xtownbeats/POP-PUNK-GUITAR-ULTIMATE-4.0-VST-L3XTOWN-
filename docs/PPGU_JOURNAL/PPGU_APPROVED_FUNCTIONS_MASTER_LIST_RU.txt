3. MELODY
3.1 Самостоятельный нотный режим: одна MIDI-клавиша = соответствующая отдельная нота гитары.
3.2 Хроматическая карта нот, root key, key range и логические диапазоны грифа.
3.3 Утверждённый трёхчастный браузер MELODY: согласованные области выбора инструмента/гитарной идентичности, тембра/пресета и исполнения/артикуляции согласно последней спецификации.
3.4 Электрические и акустические профили.
3.5 Velocity layers, velocity response, round robin при наличии дублей.
3.6 Palm mute, включая утверждённое управление palm mute через уменьшение velocity/порог.
3.7 Open/picked, sustain/release, muted articulations при наличии записей.
3.8 Legato, slide, hammer-on, pull-off и другие техники — только при наличии реальных записей и mappings.
3.9 MIDI note-on/off, sustain, overlapping notes, pitch bend, modulation.
3.10 Настраиваемые voices/polyphony, ограничение голосов и click-free voice stealing.
3.11 Дополнительный PATTERN trigger workflow внутри MELODY — только в утверждённой MIDI-зоне, не нарушая обычное поведение «одна клавиша = одна нота».
3.12 MELODY остаётся самостоятельным режимом.

4. PATTERN
4.1 Самостоятельный ритмический режим; MIDI-клавиша выбирает аккорд/voicing по утверждённой карте триггеров.
4.2 Клавиша запускает записанное аккордовое ритмическое исполнение.
4.3 Два самостоятельных окна: PRESET/GUITAR IDENTITY и PLAYING STYLE/RHYTHMIC PERFORMANCE.
4.4 Независимый выбор гитары, tone preset, playing style, pattern, articulation и variation.
4.5 Управление ритмической сеткой, gate, velocity, акцентами, humanization и вариациями.
4.6 Host tempo/transport sync, start/stop, смена аккордов/паттернов без зависших нот и обрывов.
4.7 INTRO, VERSE, PRE-CHORUS, CHORUS, BRIDGE, OUTRO; восемь Pattern Slots на каждый раздел.
4.8 Сохранение совместимости старого patternSlot state.
4.9 Реальные guitar loops/performance sets — основной источник.
4.10 Fallback из совместимых записанных one-shots, если loop не найден.
4.11 Запрет произвольного транспонирования одиночной ноты для имитации полного аккорда.
4.12 При отсутствии нужной записи — сообщить о недоступности или выбрать совместимую записанную альтернативу; не подменять гитару синтезатором.
4.13 Электрические и акустические исполнения используют соответствующие записи, а не только разные EQ.

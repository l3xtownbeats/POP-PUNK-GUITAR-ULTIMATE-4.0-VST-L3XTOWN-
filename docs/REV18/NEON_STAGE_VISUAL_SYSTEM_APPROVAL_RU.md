# Фиксация утверждения — NEON STAGE DEFAULT THEME

**Дата:** 2026-11-15  
**Проект:** POP PUNK GUITAR ULTIMATE — REV.18  
**Статус решения:** УТВЕРЖДЕНО / ЗАФИКСИРОВАНО  
**Каноническая тема:** SKIN-1 = NEON STAGE DEFAULT = skin-053 / Skin_053

Пользователь подтвердил и утвердил единый визуальный стиль NEON STAGE DEFAULT для всего интерфейса плагина, включая главное окно, все существующие и будущие панели и модули.

## Обязательное правило

Все модули используют одну дизайн-систему: общие цвета и semantic tokens, типографику, размеры/отступы, формы панелей, рамки, состояния фокуса/наведения/нажатия/отключения, регуляторы, кнопки, переключатели, селекторы, индикаторы и оформление окон.

Канонические загруженные PNG-макеты NEON STAGE DEFAULT, включая макет AutoChords, являются визуальными референсами. Компоновка каждого модуля может соответствовать его задаче, но визуальная идентичность остаётся общей. Не создавать отдельные skin/theme для AutoChords, Curator, Sound Hunter, Auto Discover, FX EDIT, AMP & TONE, Import Guitar, Settings, Performance, Skin Gallery и других частей продукта.

## Функциональная достоверность

Макет не является доказательством реализации функции. Интерактивными разрешено делать только элементы с реальными bindings/actions. Нереализованные возможности должны иметь честное disabled/deferred состояние. Запрещены фиктивные MIDI, playback, meters, scan progress, import progress и curation verdicts.

## Ограничения

- UI-only: не менять APVTS IDs/values, аудио/DSP, MIDI, sampler, scheduler, preset semantics и routing.
- Не менять существующие skin IDs и последовательную нумерацию.
- Не менять контрольные ID и существующие bindings.
- Сохранять производительность: не добавлять ненужные постоянные анимации и тяжёлые эффекты.
- Считать дизайн-систему утверждённой; дальнейшие изменения допускаются как реализация и исправление соответствия, а не как повторное предложение альтернативного визуального направления.

## Граница статуса

Утверждение визуальной системы не означает, что все панели уже интегрированы, что каждый PNG проверен в runtime, или что сборка/CTest/pluginval/FL Studio acceptance пройдены. Эти технические проверки остаются обязательными до production release.

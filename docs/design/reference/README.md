# NEON STAGE — Visual References

This directory stores approved interface mockups and visual reference material for the NEON STAGE design system.

- These images are design references, not screenshots of a running VST3 build.
- Runtime controls, APVTS bindings, layout and behaviour are defined by the source code and canonical inventories.
- Keep production skin assets under `SKIN/Skin_<index>/`; do not place runtime assets here.
- Duplicate exports and temporary captures should not be added. Use descriptive filenames and preserve the original approved artwork.

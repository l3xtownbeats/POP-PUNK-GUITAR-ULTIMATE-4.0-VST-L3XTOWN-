# POP PUNK GUITAR ULTIMATE 4.0 — интерфейс и дополнительное окно настроек

## Подтверждённое решение по интерфейсу

Основной интерфейс по умолчанию использует тёмный (чёрный) skin. Пользователь ранее также просил поддержать сменные skins из архива POP_PUNK_GUITAR_L3XTOWN_SKINS_SOURCE.zip; каждый skin должен быть отдельно проверен. Смена оформления не меняет звук, MIDI mapping, пресеты или состояние проекта.

## Основное окно

- Верхняя панель: название инструмента, индикатор выбранного skin, кнопка открытия дополнительных настроек.
- Браузер пресетов: вкладки MELODY и PATTERN, категории, поиск, избранное и список пресетов.
- Выбор пресета: один клик запускает audition/preview; повторный клик останавливает; выбор другого пресета прекращает предыдущее preview и запускает новое. Двойной клик загружает пресет в инструмент. AUTO PREVIEW ON/OFF отключает или включает автоматическое предпрослушивание.
- Центральная зона: основные параметры текущего режима и инструмента.
- Нижняя/боковая зона: основные регуляторы звучания и эффекты, доступные без открытия дополнительных настроек.

## Дополнительное окно / вкладка SETTINGS

Отдельное окно, открываемое кнопкой SETTINGS (или шестерёнкой) из основного интерфейса. Оно не заменяет основное окно и не должно перегружать его. Предусмотреть разделы:

1. **ENGINE** — Voices/Polyphony, лимит голосов, качество/нагрузка, настройки движка только если соответствующие функции реально реализованы.
2. **GUITAR & ARTICULATIONS** — поведение Velocity/Palm Mute, доступные артикуляции, настройки Melody/Pattern.
3. **EFFECTS** — расширенные параметры Distortion/Amp, Chorus, Flanger, Delay, Reverb.
4. **DOUBLE TRACK** — Double, Width, Detune, Delay, Mix и Mono Check, если функция реализована.
5. **LIBRARY** — расположение библиотек, статус доступности, сканирование/обновление индекса, предупреждения о недостающих сэмплах.
6. **PREVIEW** — AUTO PREVIEW ON/OFF, уровень предпрослушивания и темп предпрослушивания, если поддерживается.
7. **APPEARANCE** — выбор доступного skin; по умолчанию выбран тёмный/чёрный skin.
8. **PRESETS & USER DATA** — папка пользовательских пресетов/банков, импорт/экспорт и управление пользовательским контентом.

## Поведение окна

- Окно SETTINGS открывается поверх или рядом с основным окном в рамках возможностей VST3 host; если отдельное дочернее окно ненадёжно в конкретной DAW, использовать встроенную вкладку SETTINGS внутри редактора плагина.
- Закрытие SETTINGS возвращает пользователя к основному интерфейсу, не сбрасывая параметры.
- Настройки сохраняются в состоянии плагина/DAW-проекта; глобальные пользовательские предпочтения (например skin) сохраняются отдельно, если это предусмотрено архитектурой.
- Никаких фиктивных переключателей: показывать только параметры, которые действительно подключены к движку. Недоступные функции обозначать как не реализованные, а не имитировать их работу.
- Изменение оформления не должно прерывать звук или менять выбранный пресет.
- Все элементы должны быть доступны при разумном размере окна и масштабировании интерфейса.

## Статус

Это утверждённая спецификация UI, а не доказательство готовой реализации. Статус реализации подтверждается исходным кодом, сборкой, тестированием и ручной проверкой в FL Studio 20 x64.

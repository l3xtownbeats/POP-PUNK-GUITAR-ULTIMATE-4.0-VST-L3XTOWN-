# Единая организация Preset Browser — вся библиотека PPGU 5.0

Весь factory catalog (330 карточек: 165 MELODY и 165 PATTERN, 22 артиста) организован по единому принципу:

1. Основная группа — исполнитель.
2. Внутри исполнителя — звуковая семья (`Clean`, `Crunch`, `Drive`, `Palm Mute`, `Open Chords`, `Acoustic`, `Lead Drive`, `Muted Chugs` и другие фактически заданные характеры).
3. Режим `MELODY` или `PATTERN` остаётся отдельным фильтром; одноимённые пресеты обоих режимов не смешиваются по поведению.
4. Для Bloodhound Gang сохранены дополнительные группы по конкретным альбомным эпохам, поскольку для этих карточек есть явно заданные композиции, альбомы и годы.

## Правило достоверности

Не назначаем вымышленные альбомы, годы и треки другим группам. Удалены общие ошибочные track references `Bad News` / `Anthem Part Three` из карточек артистов, которым эти песни не принадлежат. Сохраняются только явно curated ссылки на треки Blink-182 и Bloodhound Gang. Для остальных групп каталог опирается на style profile, tonal target, articulation и groove, пока дискография/конкретные референсы не проверены отдельно.

## Важно о готовности аудио

Группировка и metadata пресетов не означает, что для всех 330 карточек уже поставлены реальные семплы или уникальные performance clips. В factory catalog по-прежнему отражены требования к лицензированным WAV/SFZ и к движку исполнения; готовность звука проверяется отдельно. Не включать коммерческие записи, stems или семплы без разрешающей лицензии.

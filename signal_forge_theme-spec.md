# SIGNAL FORGE / NEON — спецификация темы

## Структура папок
```
signal-forge-neon/
  assets/   — PNG-элементы интерфейса (в 2x и 4x)
  icons/    — логотип и служебные иконки
  fonts/    — шрифты темы
  config/   — theme.json и palette.json
```

## Требования к ассетам
1. Все PNG — в 2x (и опционально 4x) для Retina/4K.
2. Скругления кратны 2 px (10, 12, 16).
3. Glow НЕ запекать в PNG — рисуется движком из palette["accent.primary"].
4. Фоны панелей — с альфа-каналом, тени рисует движок.
5. Именование — snake_case, без версий в имени файла.

## Палитра
Базовая палитра в config/palette.json. Тёмная база #0B0E14, неоновый акцент #00E5FF,
ошибочный статус #FF3B5C. При смене темы правится только palette.json.

## Замена тем
Новая тема кладётся в themes/<имя-темы>/ со структурой выше.
Переключение — в настройках плагина (id из theme.json).

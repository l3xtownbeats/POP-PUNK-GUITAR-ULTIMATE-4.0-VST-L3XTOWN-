# IMPORT SAMPLE GUITAR — ручная загрузка

1. Распакуйте portable-пакет, не меняя структуру папок.
2. Откройте в плагине панель **IMPORT GUITAR**.
3. Нажмите **LOAD SFZ**.
4. Выберите карту `.sfz` внутри `Import Sample Guitar/Sample Library/`.
5. Не отделяйте SFZ от аудиофайлов, на которые ссылается карта. Сохраняйте LICENSE/атрибуцию и относительные пути.

Текущая интеграция использует SFZ loader. Самостоятельный импорт WAV и редактор velocity/key zones этим описанием не заявляются.
